Help

This page summarizes how to move around minoTour, connect the minFQ upload client, and where to find full installation and administrator documentation.

Top navigation
  • Flowcells — List and open your sequencing runs. Select a flow cell to view live metrics, reads, tasks, and analyses tied to that run.
  • MinKnow Control — Interact with MinKNOW where remote control is available (depends on your environment and permissions).
  • Client — Information about the minFQ client used to stream basecalled data and MinKNOW metrics to this server. Use your account API key from Profile details when configuring minFQ.
  • Messages — Notifications and messages associated with your account or runs (for example alerts from MinKNOW or minoTour).
  • Flowcell Split — Flowcell splitting management: pick a flow cell to split its run data (see the on-page table and actions).
  • About — What minoTour is, project links, and status.
  • Help — This guide.
Settings (gear icon)

Open the gear icon next to your username to reach account tools:

  • Manage references — Upload or select reference genomes for alignment and related analyses. You can add references privately (only your account) or as shared references, depending on how your site is configured.
  • Manage primer schemes — Manage primer scheme definitions used by supported workflows.
  • Profile details — Update contact preferences and copy your API key. The API key is required for minFQ and for command-line tools such as bulk reference import (see below).
  • Change password — Update your login password.
Uploading data with minFQ

Sequencing data and MinKNOW metrics are sent to minoTour using the separate client minFQ (Python 3; install from PyPI with pip install minFQ). Source and detailed usage: github.com/LooseLab/minotourcli.

Typical steps:

  1. Create a dedicated virtual environment if you do not already use one.
  2. Install the client: pip install minFQ (or install from a clone of the repo for development).
  3. In minoTour, open Profile details and copy your API key.
  4. Run minFQ -h for options. You will point minFQ at your watch directory, minoTour host/port, MinKNOW address, flow cell label, and pass your API key. Example shape (your paths and ports will differ): 
    minFQ -w /path/to/fastq_directory -n <flowcell_name> -k <api_key> -hn <minotour_host> -ip <minknow_host> -p <port>

minFQ can recurse under the watch directory. A config file in the working directory can hold defaults for host, port, and keys; see the minFQ repository for examples.

References and larger genomes

Alignments and several analyses need reference sequences added under Manage references. The in-browser upload is limited to 256 MB per file; for larger references, use the management command on the server with your API key, for example: 

python manage.py add_references -k <your_api_key> /path/to/reference.fa

Run python manage.py add_references -h on the server for full options. If an identical reference already exists, minoTour will tell you which entry to use.

Administrator and advanced setup

Hosting minoTour requires MySQL, Redis, Celery workers, and environment configuration (envs.sh). Metagenomics (Centrifuge), Artic-related conda environments, and optional integrations such as Twitter notifications are described in the project README.

For a containerized deployment, see the Docker Compose project: github.com/LooseLab/minotour-docker.

If you are logged in as a Django superuser, minoTour shows a warning: use a non-admin account for routine sequencing and analysis work.

Experimental features

Some capabilities—especially parts of metagenomics and real-time SV/CNV analysis—are still experimental. Treat results as provisional and validate critical findings with independent methods.

Documentation, issues, and videos
  • Repository & full README: github.com/LooseLab/minotourapp — installation, services (Redis, Celery, Flower), reference to metagenomics indexes, and more.
  • Bug reports & feature requests: use GitHub Issues on the same repository.
  • Video tutorials: step-by-step screencasts are planned; when published they will typically appear on YouTube. If you run minoTour fully offline, open those links on a machine with internet access or refer to this Help page and the README instead.
