About

minoTour is a web-based laboratory information management system (LIMS) for Oxford Nanopore Technologies (ONT) sequencers, built with Django. It is designed to run locally (for example on a laptop) or on a server so it can be accessed remotely.

The application monitors Nanopore instruments in near real time: it integrates with ONT’s minKNOW API for live run metrics and device context, and can parse sequence files as they are produced—so you get insight into performance and run health without waiting only on fully basecalled outputs. You can track flow cell QC, review messages from MinKNOW, and (where configured) use remote control features. Downstream, minoTour supports simple analyses such as basecalling summaries, alignment, and metagenomics, in real time or after a run.

Data upload from sequencing machines uses the companion client minFQ (PyPI / minotourcli on GitHub).

Project status

minoTour is under active development. Features may change; you may encounter bugs or rough edges. Bug reports, feature requests, and pull requests are welcome on the open-source repository: github.com/LooseLab/minotourapp.

For deployment, a Docker Compose setup is maintained in the sister repository LooseLab/minotour-docker.

Some areas—especially parts of metagenomics and real-time structural variant (SV) and copy-number (CNV) detection—are experimental and may be incomplete. Treat results accordingly.
